01 · 这是什么

输入几点点单碎片（时段 / 辣度 / 冰量 / 用券习惯 / 加购冲动），「麦门侧写师」会输出一份黑客终端风格的行为侧写报告——然后调用麦当劳 MCP，按"人格裁定"自动完成查菜单、领券、计价，确认后创建一笔真实订单。

先读懂你，再喂饱你。 好玩（侧写报告即社交货币）× 实用（真实点餐且自动省钱），一个闭环全占。

03 · 安装方法（3 步接入真实 MCP）

① 申请麦当劳 MCP Token

访问 open.mcd.cn/mcp，手机号登录，控制台点击【激活】。

② WorkBuddy 配置连接器

【连接器】→【自定义连接器】→【配置MCP】，粘贴（替换 YOUR_MCP_TOKEN）：

{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": { "Authorization": "Bearer YOUR_MCP_TOKEN" }
    }
  }
}

③ 安装 Skill

把仓库 skill/ 目录放入 ~/.workbuddy/skills/mcd-profiler/，然后对 AI 说："麦门侧写我" 或 "我加班到现在，侧写完直接帮我点了"。

04 · MCP 调用链（侧写如何变成真实订单）

now-time-info（校准真实时段）
  → query-nearby-stores / delivery-query-stores（锁定门店）
  → query-meals → query-meal-detail（"人格套餐" → 真实餐品编码）
  → available-coupons → auto-bind-coupons（按人格标签领券配券）
  → calculate-price（报出应付总价 → 双确认）
  → create-order（创建订单，返回支付链接）

13 个 MCP Tool 的完整业务映射见仓库 MCP_INTEGRATION.md。下单前强制二次确认，取消路径始终可用（cancel-order）。
