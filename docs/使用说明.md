# 麦门侧写师 McProfiling · 使用说明

> 点单即人格。你点的每一份麦当劳，都是潜意识递出的自白书。
> 本文档是 WaytoAGI 1024 用餐赛道 × 麦当劳程序员创意开发大赛参赛作品的使用指南。

## 一、产品简介

「麦门侧写师」是一个基于**麦当劳 MCP** 的 Skill：

1. **侧写**：输入点单碎片（时段、辣度、冰量、用券习惯、加购冲动，最少 1 项即可），
   输出黑客终端风格的 6 模块心理侧写报告——点单硬件与底层电压 → 模态解码与防御机制 →
   散弹枪高频切片 → 口味信任鉴权 → 降维进食协议 → 麦门金句。
2. **落单**：侧写完成后，按"人格套餐"自动走 MCP 真实调用链：查菜单 → 领券 → 计价 →
   你确认后创建订单，返回支付链接。
3. **省钱**：识别到"资源焦虑型 / 薅券之神"人格标签时，自动领取并匹配最优优惠券。

## 二、快速体验（不需要任何配置）

- **网页演示**：浏览器打开 `submission/mcd-profiler-作品页.html`（单文件，封面、介绍、
  可玩 Demo、使用说明全部内嵌），直接在页面里"启动侧写引擎"。
- **离线 Demo**：浏览器打开 `demo/index.html`。
- 完整侧写报告样张见 `skill/examples/report-samples.md`。

## 三、接入真实麦当劳 MCP（3 步）

### 第 1 步：申请 MCP Token

1. 访问 [open.mcd.cn/mcp](https://open.mcd.cn/mcp)
2. 手机号验证登录（右上角"登录"→ 变为"控制台"）
3. 点击控制台【激活】，同意服务协议，复制 MCP Token

### 第 2 步：在 WorkBuddy 配置连接器

左侧边栏【专家·技能·连接器】→【连接器】→ 右上角【自定义连接器】→【配置MCP】，
粘贴以下 JSON（**替换 `YOUR_MCP_TOKEN`**）后保存并启用：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

> 注意：Token 限速 600 次/分钟；请勿在对话中明文粘贴 Token。

### 第 3 步：安装 Skill

将仓库 `skill/` 目录内容放入 WorkBuddy 用户技能目录：

```
~/.workbuddy/skills/mcd-profiler/
├── SKILL.md
├── references/
│   ├── profiling-engine.md
│   └── mcp-playbook.md
└── examples/
    └── report-samples.md
```

## 四、怎么用（示例对话）

**只侧写，不点餐：**

```
你：周五 21:47，刚加班完，常点麦辣鸡腿堡中套餐可乐去冰，今天加购了香芋派。侧写我。
AI：（输出 6 模块侧写报告，以麦门金句收尾）
```

**侧写完直接下单：**

```
你：我加班到现在，心情很差，侧写完直接帮我点了。
AI：（侧写报告）人格套餐已裁定：麦辣鸡腿堡中套餐（可乐去冰）+ 香芋派。
    已为你领券，用券后应付 ¥33.50。确认下单吗？
你：确认。
AI：订单已创建，支付链接：https://…（完成支付即下单成功）
```

**侧写历史点单：**

```
你：翻翻我的历史订单，侧写一下我是什么人。
AI：（调用 order-list 读取近期订单 → 输出群体侧写）
```

其他可用说法："麦门侧写我"、"根据我上次点单猜猜我是谁"、"我们聚餐，按大家口味出个人际电压图谱"。

## 五、MCP 工具链一览

| 阶段 | 工具 |
|---|---|
| 时段校准 | `now-time-info` |
| 门店锁定 | `query-nearby-stores` / `delivery-query-stores` |
| 菜单匹配 | `query-meals` → `query-meal-detail` |
| 营养佐证 | `list-nutrition-foods` |
| 优惠执行 | `available-coupons` → `auto-bind-coupons` / `query-store-coupons` |
| 价格核算 | `calculate-price` |
| 订单执行 | `create-order`（双确认后）/ `cancel-order` |
| 状态回溯 | `query-order` / `order-list` |

完整映射与调用流程见 `MCP_INTEGRATION.md`。

## 六、安全与声明

- 侧写为**娱乐化心理演绎**，不构成真实心理评估、医疗或营养建议。
- 侧写对象仅限本人或知情同意者；拒绝侧写陌生第三方。
- 调用 `create-order` 前强制向用户复述订单明细与金额并二次确认；随时可用 `cancel-order` 取消。
- 本项目不存储任何真实 Token；餐品、价格、供应状态以麦当劳官方渠道实时结果为准。
- 本项目为参赛者独立开发，非麦当劳官方产品。

## 七、常见问题

**Q：不申请 Token 能用吗？**
能。`demo/index.html` 与作品页内置离线演示，侧写报告完整可玩，仅"真实下单"需要 Token。

**Q：调用返回 401 / 429？**
401 = Token 无效或过期，重新检查配置；429 = 超过 600 次/分钟限流，稍后再试。

**Q：支持外送吗？**
支持。外送场景会走 `delivery-query-stores` 查询可配送门店，若无地址会引导用 `delivery-create-address` 创建。
